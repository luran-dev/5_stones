# 한 수 — 컴퓨터와 즐기는 오목

브라우저에서 컴퓨터와 대결하는 15×15 오목 게임입니다. HTML 파일 하나에 화면과 게임 로직이 들어 있어 별도의 설치나 빌드 없이 플레이할 수 있습니다.

## 실행 방법

### HTML 파일 직접 열기

1. 이 저장소를 다운로드하거나 복제합니다.
   ```bash
   git clone https://github.com/luran-dev/5_stones.git
   cd 5_stones
   ```
2. `gomoku/dist/index.html` 파일을 브라우저로 엽니다.
3. 바둑판의 빈 교차점을 클릭하면 바로 시작됩니다.

macOS에서는 저장소 루트에서 다음 명령으로 열 수도 있습니다.

```bash
open gomoku/dist/index.html
```

인터넷 연결이나 Node.js 없이도 게임을 즐길 수 있습니다. 최신 Chrome, Edge, Firefox, Safari 등에서 실행하세요.

### 로컬 서버로 실행하기

Python 3가 설치되어 있다면 저장소 루트에서 실행합니다.

```bash
python3 -m http.server 8000 --directory gomoku/dist
```

브라우저에서 <http://localhost:8000>에 접속합니다. 서버를 종료하려면 터미널에서 `Ctrl+C`를 누릅니다.

### 게시된 게임 이용하기

[오목 게임 바로 플레이하기](https://five-stones-jasper-1030.noisymyna21.chatgpt.site)

게시된 사이트는 소유자 전용으로 설정되어 있어 계정에 따라 접근이 제한될 수 있습니다. 로컬 HTML 파일은 로그인 없이 실행할 수 있습니다.

## 게임 방법

1. 사용자는 **흑돌**, 컴퓨터는 **백돌**입니다. 사용자가 먼저 둡니다.
2. 빈 교차점을 클릭하거나 터치하면 흑돌을 놓습니다.
3. 컴퓨터가 백돌을 놓으면 다시 사용자 차례가 됩니다.
4. 가로, 세로, 대각선 중 어느 방향이든 같은 색 돌을 **5개 이상 연속**으로 놓으면 승리합니다.
5. 승자 없이 바둑판이 가득 차면 무승부입니다.

**자유룰**을 사용합니다. 삼삼·사사 등의 금수가 없으며, 6개 이상 이어지는 장목도 승리로 인정합니다. 이미 돌이 놓인 자리에는 둘 수 없으며, 컴퓨터가 생각하는 동안에는 추가로 착수할 수 없습니다.

## 조작과 기능

| 조작 / 기능 | 설명 |
| --- | --- |
| 클릭 / 터치 | 빈 교차점에 돌을 놓습니다. |
| 방향키 | 바둑판에 키보드 초점이 있을 때 상하좌우로 이동합니다. |
| Enter / Space | 키보드 초점이 있는 교차점에 돌을 놓습니다. |
| 한 수 되돌리기 | 컴퓨터가 응답한 뒤에는 사용자와 컴퓨터의 돌을 한 개씩 되돌립니다. 컴퓨터가 생각 중이면 사용자의 마지막 돌만 취소합니다. |
| 새 게임 시작 | 바둑판을 비웁니다. 진행 중인 대국이 있으면 확인 창이 표시됩니다. |
| 마지막 착수 표시 | 가장 최근에 놓인 돌의 가운데에 작은 점을 표시합니다. |
| 승리 표시 | 승리를 만든 연속된 돌을 강조합니다. |

키보드로 플레이하려면 `Tab`으로 바둑판에 초점을 옮긴 다음 방향키와 `Enter` 또는 `Space`를 사용하세요. 모바일에서는 화면 너비에 맞춰 바둑판과 조작 영역이 세로로 배치됩니다.

### 컴퓨터 난이도

- **가볍게 · 쉬움**: 상위 후보 중에서 무작위로 수를 선택합니다.
- **차분하게 · 보통**: 공격과 방어 점수를 계산해 수를 선택합니다.
- **치열하게 · 어려움**: 후보에 돌을 놓았을 때 상대에게 생기는 위협도 평가합니다.

모든 난이도에서 컴퓨터는 즉시 이길 수 있는 수를 우선하며, 상대가 다음 수에 이길 수 있다면 이를 막습니다. 난이도 변경은 컴퓨터의 다음 수부터 적용됩니다. 컴퓨터는 브라우저 안에서 실행되는 점수 기반 알고리즘이며, 외부 AI 서비스나 API 키는 사용하지 않습니다.

## 파일 구성

```text
5_stones/
├── README.md                  # 실행 및 게임 안내
└── gomoku/
    ├── dist/
    │   └── index.html         # 게임 화면, 스타일, 게임 로직
    ├── check.cjs              # 게임 로직 테스트
    ├── DESIGN.md              # 디자인 및 접근성 기준
    ├── README.md              # 게임 디렉터리 간단 안내
    └── .openai/hosting.json   # Sites 게시 설정
```

화면이나 게임 로직을 수정하려면 `gomoku/dist/index.html`을 편집한 뒤 브라우저를 새로고침하세요. 별도 빌드 과정은 없습니다.

## 테스트

테스트 실행에는 Node.js가 필요합니다. 의존성 패키지를 설치할 필요는 없습니다.

```bash
cd gomoku
node check.cjs
```

성공하면 `PASS:`로 시작하는 결과가 출력됩니다. 테스트는 바둑판 생성, 차례 제어, 컴퓨터 응답, 되돌리기와 대기 중 착수 취소, 네 방향의 승리 판정, 컴퓨터의 즉시 승리·방어 선택, 종료 후 착수 방지 및 대국 완료를 확인합니다.

이 테스트는 간단한 DOM 대체 객체를 사용하므로 실제 브라우저의 화면 배치나 터치·키보드 동작까지 검증하지는 않습니다.

## 참고 사항

- 대국 상태는 자동 저장되지 않습니다. 새로고침하거나 탭을 닫으면 진행 상황이 사라집니다.
- 사용자와 컴퓨터의 돌 색 및 선후공은 고정되어 있습니다.
- 온라인 사용자 간 대전은 지원하지 않습니다.
