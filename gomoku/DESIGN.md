# 한 수
Task-first, buildless Korean board game. Warm ivory page (#f5f3ee), ink (#272a25), forest green (#425d48), wood board (#ddbb86). System Korean sans serif with a serif display title. Desktop: large board left, compact game controls right; mobile: board and controls stack. Spacing 8/12/16/24/32/48px, corners 12/20px. Real CSS shaded stones, fine board lines, small last-move mark. Buttons share visible keyboard focus, disabled states and 140ms feedback. No external fonts or image dependencies. Board supports arrow keys and Enter, live turn announcements, reduced motion. Rules: freestyle, five or more wins, no forbidden moves. Difficulty uses local tactical scoring; not a professional engine.
